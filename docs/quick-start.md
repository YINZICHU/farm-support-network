# 本地虚构预览

需要 Node 24.19.0 与 pnpm 11.19.0。在模板根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm demo
```

打开终端显示的 `http://127.0.0.1:4182/farm-support/manage/`。此地址仅本机可用，不是公共网站。保持终端运行；按 Ctrl+C 停止。

终端还会显示一个操作系统临时目录内的 `local-demo-access.json` 路径。仅在你自己的电脑上用文本编辑器打开它；输入其中的虚构邮箱和随机密码登录。每次启动生成新的独立存储与密码，没有通用演示密码。不要把账号文件、密码、截图或任何密钥发送到聊天、Issue 或 Git。

初始状态为 PREPARING，业务资料为空。默认“示例村甲 / 示例村乙”并不代表真实村庄；只能登记虚构资料。在“村庄与权限”查看筹备状态、新增或更名虚构村庄；在“人员与时段”“需求登记”核实时段、查看候选。候选不会自动接单，每一方须另行确认。“操作与运维指南”解释角色权限、准备/开放/暂停和人工备份。演示不发送邮件、不公开注册、不访问正式存储，也不提供真实服务。账户是本实例邮箱登录，不需要 ChatGPT 账号；本地演示不强制 MFA，不能据此省略生产的管理账号 MFA。

右上角切换中文/English，同一身份的未提交草稿保留；退出或授权改变会清除私人视图。可使用 `?lang=zh` / `?lang=en` 直接选界面语言；公共工具入口为 `/zh/tools/` / `/en/tools/`。下载标明原件语言、格式和大小，不会生成不存在的译本。

预览绑定 127.0.0.1，忽略全部 `FARM_*` 生产变量，并在 `NODE_ENV=production` 时拒绝运行。4182 被占用时先停止你自己的旧演示，不要关闭不认识的服务。两次预览不会共享数据库；停止后临时目录仍保留，仅私下删除终端显示的那一个演示目录，勿删除上级目录。

编辑 [项目配置](../config/project.json) 后重新构建：同一份配置同时用于界面、初始化和授权。种子村庄 ID 必须稳定且唯一，已建立的数据库不能直接换种子 ID。运行中通过授权工作台新增的村庄保存在数据库，不必改配置。前端与后端配置不同会拒绝进入工作台。空联系邮箱/主网站字段不会显示可点击链接。

此预览不是正式部署，Windows 也不是支持的生产环境。正式部署只支持 Linux 单实例、独立密钥和 `/var/data/farm-support` 持久卷；请先读 [部署说明](deployment.md)、[操作与恢复](operations.md)。不要在演示目录存放真实村民资料。

## 配置后的回归测试

`pnpm test` 的应用测试使用共享配置中的村庄 ID。实际配置只有一个村时，跨村权限回归只在测试进程内存中加第二个虚构权限范围，不修改配置文件；另有独立进程测试真实单村、双村、三村初始化、邀请和撤权，不加这个范围。`node tests/configured-suite.mjs` 会再用临时源码副本跑完整的单村、三村测试，Node 与 Vite 读取同一份副本配置。定制项目时不要删除不同意、跨村拒绝或 MFA 的断言。
