## 环境与证据边界

自动测试的生产存储使用虚构资料和模拟已验证挂载；真实生产 HTTP/TOTP 测试验证权限及 MFA 门槛，不能据此认定部署挂载合格。本机 demo 不强制 MFA，不能据此取消生产 MFA。读屏验收是 DOM 标签、role、live-region 与键盘检查，不是实际屏幕阅读器朗读测试。浏览器系统 reduced-motion 未开启，另检查 CSS 关闭非必要动画的规则。

## 本轮功能

- 运行中村庄注册表：新增、更名、筹备/开放/暂停/关闭、容量；稳定ID，保留历史及安全收尾，不提供物理删除。
- 显式项目管理员、新增权、指定村管理权；普通账号不能扩大自己的权限，按村隔离，缩减权限清会话，旧邀请/备份不能绕过最新权限边界。
- 共享中英字典覆盖工作台、登录/MFA、表单、指南、打印、状态和错误。语言切换保留同一身份输入；授权/身份变动丢弃私密资料、旧异步结果及表单。
- 公共工具页使用同一份目录，不访问私人业务接口。精确路径、字节数、原始 SHA-256 独立批准，静态与源包检查同名替换和未知文件。
